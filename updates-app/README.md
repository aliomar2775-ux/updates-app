# سجل تحديث الأجهزة — دليل التشغيل

## التشغيل
1. ارفع مجلد المشروع كاملاً إلى السيرفر (يتطلب Node.js 18 أو أحدث).
2. داخل المجلد نفّذ:  `npm install`  ثم  `npm start`
3. افتح  `http://عنوان-السيرفر:3000`  من أي جهاز — كل الأجهزة تكتب في نفس ملف Excel.

## أين الملف؟
`data/updates.xlsx` على السيرفر. يُحدَّث تلقائياً عند كل حفظ أو تعديل أو حذف.
- لمتابعة ملف قديم: ضعه في مجلد `data` باسم `updates.xlsx` قبل تشغيل الخادم.
- لا تعدّل الملف يدوياً أثناء تشغيل الخادم (أعد تشغيل الخادم بعد أي تعديل يدوي).
- زر «تنزيل ملف Excel» في الصفحة ينزّل نسخة عند الطلب فقط.

## إعدادات اختيارية (متغيرات بيئة)
| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | 3000 |
| `APP_USER` / `APP_PASS` | تفعيل حماية باسم مستخدم وكلمة مرور | معطّلة |
| `DATA_DIR` | مكان حفظ ملف Excel | `./data` |
| `TZ_NAME` | المنطقة الزمنية للتاريخ والوقت | Asia/Baghdad |

مثال:  `APP_USER=admin APP_PASS=1234 npm start`

للتشغيل الدائم على السيرفر يُنصح باستخدام `pm2 start server.js`.
